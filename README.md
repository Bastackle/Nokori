# Nokori - Clothing E-commerce Website

An e-commerce application showcasing both frontend design and fullstack development.

## Branch Overview

- [`frontend-concept`](https://github.com/Bastackle/Nokori/tree/frontend-concept): Pure frontend showcasing the design and functionality using mock data.
- `fullstack`: Fullstack version with backend API integration (COMING SOON).

## Tech Stack

- **Frontend**: Vue.js, Vite, Tailwind CSS, DaisyUI
- **Backend**: Firebase (Authentication, Firestore Database)

## ✨ Features

- **Product Listing**: Display products in a grid layout, with filtering and sorting options.
- **Product Details**: Show detailed product information including images, descriptions, and available sizes.
- **Add to Cart**: Users can add items to their cart (frontend only/fullstack).
- **Authentication**: full authentication using Firebase in fullstack version.
- **Search**: Search for products.
- **Responsive Design**: Fully responsive layout for various devices.
- **Order Management**: Simulate order placement and order history management in the fullstack version. (frontend only/fullstack)
